# kartavyaa-voice-detection-Buildathon
Kartavyaa is an AI-powered API that detects whether audio is AI-generated or human speech. Using multi-layer Gemini 2.5 Pro analysis of acoustic features and naturalness patterns, it returns classification with confidence scores in under 30 seconds. Built for HCL-GUVI AI Impact Summit Buildathon to combat deepfake voice fraud.
